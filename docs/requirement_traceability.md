## Current Hard Blocker

The pinned Chromium checkout cannot complete the baseline `content_shell` build until ATL/MFC headers are installed:

```text
fatal error: 'atldef.h' file not found
```

The required Visual Studio component is:

```text
Microsoft.VisualStudio.Component.VC.ATLMFC
```

Install from an elevated PowerShell:

```powershell
.\scripts\install_vs_atl.ps1
```

The installer script fails if post-install verification cannot find `atldef.h` or if `vswhere -requires Microsoft.VisualStudio.Component.VC.ATLMFC` does not report the component for the Build Tools installation.

Then resume with:

```powershell
.\scripts\verify_prebuild.ps1
.\scripts\run_post_atl_pipeline.ps1 `
  -RefreshChromiumPin `
  -IncludeWebGPU `
  -IncludeAggressiveGpu `
  -AggressiveAngleBackend d3d11 `
  -CaptureTrace `
  -RunTrustedExperimentMatrix `
  -TrustedMatrixInProcessGpu `
  -TrustedMatrixSingleProcess `
  -TrustedMatrixAngleBackend d3d11 `
  -TrustedMatrixReservedNoopGates `
  -RunLongStability `
  -MaxRssDeltaMb 128 `
  -MaxRendererResourceDelta 0 `
  -FinalGate
```
