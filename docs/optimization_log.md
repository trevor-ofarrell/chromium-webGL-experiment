# Optimization Log

Date: 2026-05-21

This log records the final decision state for the Chromium-derived Three.js viewer runtime at Chromium revision `3a94d90ec3c04556622c56944796dd76753e0581` and fork revision `3a94d90ec3c04556622c56944796dd76753e0581+viewerpatch-cca4b9171b07`.

Allowed final optimization statuses are `kept`, `reverted`, `blocked`, or `not useful`.

Primary evidence:

- Official manifest: `benchmarks/reports/official-comparison-manifest.json`
- WebGL2 report: `benchmarks/reports/official-webgl2-comparison.md`
- WebGPU report: `benchmarks/reports/official-webgpu-comparison.md`
- Trusted matrix manifest: `benchmarks/reports/trusted-experiment-matrix-manifest.json`
- Trusted WebGL2 report: `benchmarks/reports/trusted-experiment-matrix-webgl2-comparison.md`
- Stability artifacts: `benchmarks/raw/baseline-content-shell-long-stability-instancing-webgl2.json`, `benchmarks/raw/fork-viewer-default-long-stability-instancing-webgl2.json`
- Runtime target: Chromium `content_shell`

Official WebGL2 default fork results versus stock content shell: package size -130.3 MB, average startup -220 ms across the scene suite, average FPS -1.3%, average p99 frame time -28.8 ms, average CPU frame time -0.06 ms, and average render submission -0.05 ms. Official WebGPU default fork results versus stock content shell: package size -130.3 MB, average startup -12 ms, average RSS -15.3 MB, average FPS -24.6%, and average p99 frame time +135.9 ms. WebGPU GPU timestamp timing is disabled in official WebGPU evidence because timestamp queries caused device loss during stress runs; adapter/device metadata remains captured.

## Kept Default Changes

- Content-shell-derived executable with viewer mode, no browser chrome, one `WebContents`, direct local viewer URL, and external navigation lock.
- Benchmark launch policy with background networking, extensions, sync, component update, translate, and autofill server communication disabled.
- Hardware GPU fail-closed launch and validation through `--disable-software-rasterizer`, GPU metadata checks, and software-renderer rejection.
- Packaged local viewer assets and seven deterministic scenes for WebGL2 and WebGPU where supported.

## Trusted Experiment Flags

The following are retained only behind `--viewer-trusted-content` and explicit viewer experiment flags: `--viewer-aggressive-gpu`, `--viewer-force-angle-backend=d3d11`, `--viewer-relaxed-webgl-validation`, `--viewer-in-process-gpu`, and `--viewer-single-process`. The no-op gates `--viewer-disable-unneeded-blink-features` and `--viewer-direct-gpu-presentation` remain reserved for future source work and are not default optimizations.
